## 工具使用方法

### 用户交互示例
用户可以通过语音或文本询问：
- "报销制度是什么？"
- "出差申请需要什么流程？"
- "年假怎么申请？"
- "考勤规定有哪些？"

### 函数调用格式
```python
company_policy_query(
    policy_type="报销",  # 制度类型
    query="出差报销的标准和流程",  # 具体问题
    timeout=60  # 超时时间
)
```

## 技术架构

### 数据流
1. 用户输入 → 意图识别 → 函数调用
2. 函数处理 → FastGPT API请求 → 流式响应
3. 数据解析 → 实时输出 → 用户接收

### 错误处理机制
1. **网络错误**: 处理API请求失败、超时等情况
2. **数据解析错误**: 处理JSON解析失败、数据格式错误等
3. **备用请求**: 流式请求失败时自动尝试非流式请求
4. **日志记录**: 详细记录所有操作和错误信息
