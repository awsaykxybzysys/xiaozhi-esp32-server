# 公司行政制度查询工具

## 概述

公司行政制度查询工具是一个基于FastGPT API的流式查询工具，专门用于查询公司各项行政制度和政策。该工具支持实时流式输出，能够快速响应用户关于公司制度的各种问题。

## 功能特性

- **流式输出**: 实时返回查询结果，提供更好的用户体验
- **多制度支持**: 支持报销、出差、请假、考勤、福利、培训、晋升等多种制度类型
- **智能查询**: 基于FastGPT API，提供智能化的制度查询和解答
- **灵活配置**: 支持自定义API地址、密钥和超时时间
- **错误处理**: 完善的错误处理和日志记录机制

## 支持的政策类型

- **报销制度**: 差旅费、办公用品、培训费等各类报销标准
- **出差制度**: 出差申请流程、审批权限、费用标准等
- **请假制度**: 年假、病假、事假等各类假期的申请和管理
- **考勤制度**: 工作时间、迟到早退、加班等考勤规定
- **福利制度**: 员工福利、保险、补贴等福利政策
- **培训制度**: 培训申请、费用报销、培训记录等
- **晋升制度**: 晋升标准、评估流程、薪资调整等

## 配置说明

### 1. 配置文件设置

在 `config.yaml` 文件中添加以下配置：

```yaml
plugins:
  company_policy_query:
    api_url: "https://cloud.tryfastgpt.ai/api"  # FastGPT API地址
    api_key: "your-fastgpt-api-key"  # FastGPT API密钥
    timeout: 60  # 超时时间（秒）
    default_policy_types: ["报销", "出差", "请假", "考勤", "福利", "培训", "晋升"]
    cache_ttl: 1800  # 缓存时间（秒），30分钟
```

### 2. 启用工具

在意图识别配置中启用该工具：

```yaml
Intent:
  function_call:
    functions:
      - company_policy_query
      # 其他工具...
```

## 使用方法

### 1. 基本查询

用户可以通过语音或文本询问公司制度相关问题，例如：

- "报销制度是什么？"
- "出差申请需要什么流程？"
- "年假怎么申请？"
- "考勤规定有哪些？"

### 2. 具体查询

工具会自动识别制度类型和具体问题，例如：

- 制度类型：报销
- 查询内容：出差报销的标准和流程

### 3. 流式输出

工具会实时返回查询结果，用户可以立即看到部分答案，而不需要等待完整响应。

## API接口

### 函数签名

```python
async def company_policy_query(
    conn, 
    policy_type: str, 
    query: str, 
    timeout: int = 60, 
    stream_callback=None
) -> ActionResponse
```

### 参数说明

- `conn`: 连接对象，包含配置信息
- `policy_type`: 制度类型（报销、出差、请假、考勤、福利、培训、晋升、其他）
- `query`: 具体查询内容或问题
- `timeout`: 超时时间（秒），默认60秒
- `stream_callback`: 流式回调函数，用于处理实时数据

### 返回值

返回 `ActionResponse` 对象，包含：
- `action`: 动作类型（STREAM_RESPONSE 或 ERROR）
- `result`: 结果描述
- `response`: 错误信息（如果有）

## 错误处理

工具包含完善的错误处理机制：

1. **网络错误**: 处理API请求失败、超时等情况
2. **数据解析错误**: 处理JSON解析失败、数据格式错误等
3. **配置错误**: 处理API密钥无效、配置缺失等

2. 在配置文件的 `default_policy_types` 中添加新类型

可以修改 `request_data` 中的 `system` 消息内容，以定制AI助手的回答风格和内容。
